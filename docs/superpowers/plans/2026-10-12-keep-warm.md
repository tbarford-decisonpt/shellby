# Keep warm Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Keep warm button in Shellby's tab strip. While it's on, every conversation with a warm one-hour prompt cache gets one tiny message 5 minutes before that cache would expire, so the first message after a break reads from the cache instead of rewriting it.

**Architecture:** A pure rules module (`src/main/keepwarm.js`) decides, per tab and per 30-second tick, whether to ping, wait, skip or drop. A service (`src/main/keepwarm-service.js`) runs those rules against the tab manager. It holds the power blocker and pushes state to the panel. The tab manager gains `ping()`, which sends one message through the tab's already-running Claude process and swallows that turn's items, so History, unread, effort and steering stay untouched. The panel gets a button with a countdown and tooltip, plus a dim receipt line that also ends the turn in the panel.

**Tech Stack:** Electron, plain JS (no renderer framework), `node:test`, the fake Claude CLI (`test/fixtures/fake-claude.js`), and CDP e2e scripts.

**Spec:** `docs/plans/keep-warm.md`. Read it before starting any task.

**Worktree:** `C:\RAD\shellby\.claude\worktrees\keep-warm`, branch `keep-warm`, based on `file-viewer` (PR 29). Every path below is relative to it.

## Review Focus

1. **You type while a ping is in flight.** The panel shows the tab busy, so your message queues. It must not be steered into the ping's turn and swallowed: `takeSteers` returns `[]` while pinging (Task 2 test). It must go out once the receipt arrives: `boot.js` calls `SB.onTurnEnded` for receipts with `endsTurn` (Task 5 test).
2. **The PC slept through the expiry.** The first tick after waking finds the cache already expired. The tab must be dropped with "it went cold at HH:MM", not pinged into a full write (Task 3 test).
3. **A kept tab is closed.** It must leave the kept set without a ping or a receipt (Task 3 test).
4. **A kept tab's process dies** (crash, or Claude Code updated underneath). The tab must be dropped with "its Claude Code process ended" instead of pinged (Task 1 and Task 3 tests).
5. **A drop line arrives while the tab is running a turn of yours.** Only receipts that end a ping carry `endsTurn`. A tick's drop line must not clear the panel's busy state or drain your queue (Task 3 and Task 5 tests).
6. **Three tabs are due at once.** Pings go one at a time. A pinging tab is left out of `aggregate`, so the crab doesn't start working, the tray doesn't say "running" and the Multitasker trophy doesn't count it (Task 2 and Task 3 tests).
7. **You come back to a reopened conversation.** The receipt line must still be there, which means it is saved in History (`PERSISTED`) (Task 2 test against the real History).

```js
// Keep warm (docs/plans/keep-warm.md): which conversations get a ping and when,
// what a ping's readback says, and when you're back. Pure: keepwarm-service.js
// brings the tabs and the clock.
const MIN = 60 * 1000;
const HOUR = 60 * MIN;
const LEAD_MS = 5 * MIN;        // a ping goes this long before the cache would expire
const MAX_MS = 3 * HOUR;        // on for no longer than this, however long you're gone
const TICK_MS = 30 * 1000;      // how often the tabs are looked at
const AWAY_IDLE_MS = 2 * MIN;   // no input for this long and you've stepped away (recap.js IDLE_MS)
const COLD_SHARE = 0.1;         // a ping that wrote this share of what it read found the cache gone,
const COLD_MIN_WRITE = 10000;   // as long as it wrote this much: every ping writes ~2.6k of its own
const PING_TEXT = 'Keep-warm ping from Shellby. Reply with the single word: warm. Use no tools.';

const pad = n => String(n).padStart(2, '0');
/** 13:05, in this PC's time. */
function hhmm(ms) {
  const t = new Date(ms);
  return `${pad(t.getHours())}:${pad(t.getMinutes())}`;
}
/** 214k, or the number itself under a thousand. */
function tokensText(n) { return n >= 1000 ? `${Math.round(n / 1000)}k` : String(n || 0); }

/**
 * What to do with each open tab this tick.
 * tabs: [{ id, title, saved, hasProc, inTerminal, busy, pending, crew, cache: { at, ttlMs } | null }]
 * kept: Map tabId -> { state: 'kept' | 'dropped', reason }, what the service already decided
 * -> [{ id, title, action, reason, dueAt }], action:
 *   'ping' due now; 'wait' kept, not due (reason 'working' while it's busy);
 *   'skip' not one to keep warm; 'drop' was kept and can't be any more
 */
function plan(tabs, kept, now, lead = LEAD_MS) {
  return tabs.map(t => {
    const k = kept.get(t.id);
    const out = (action, reason = null, dueAt = null) => ({ id: t.id, title: t.title, action, reason, dueAt });
    if (k?.state === 'dropped') return out('skip', k.reason);
    if (k && !t.hasProc) return out('drop', 'its Claude Code process ended');
    if (!t.saved || !t.hasProc || t.inTerminal || !t.cache) return out('skip', 'nothing to keep warm');
    if (!(t.cache.ttlMs >= HOUR)) return out('skip', 'its cache only lasts 5 minutes');
    const expires = t.cache.at + t.cache.ttlMs;
    const dueAt = expires - lead;
    // Its own turn reads (and restamps) the cache: nothing to do but wait.
    if (t.busy || t.pending || t.crew) return out('wait', 'working', dueAt);
    // Past it (the PC slept, say): a ping now would pay the whole write.
    if (now >= expires) return k ? out('drop', `it went cold at ${hhmm(expires)}`) : out('skip', 'its cache is already cold');
    return out(now >= dueAt ? 'ping' : 'wait', null, dueAt);
  });
}

/** A ping's readback ({ ok, error, tokens, denied } from manager.ping) -> { warm, read, wrote, reason }. */
function receipt(r) {
  if (r?.denied) return { warm: false, read: 0, wrote: 0, reason: 'the ping tried to use a tool' };
  if (!r?.ok) return { warm: false, read: 0, wrote: 0, reason: String(r?.error || 'the ping failed').split('\n')[0] };
  const read = r.tokens?.cacheRead || 0;
  const wrote = r.tokens?.cacheWrite || 0;
  // Read nothing, or wrote a good part of it again: the cache had already gone.
  if (!read || (wrote >= read * COLD_SHARE && wrote >= COLD_MIN_WRITE)) return { warm: false, read, wrote, reason: `the ping found it cold (read ${tokensText(read)}, wrote ${tokensText(wrote)})` };
  return { warm: true, read, wrote, reason: null };
}

/** One idle reading while it's on. left: you've stepped away since it went on. -> { left, back } */
function watchBack(left, { idleMs = 0, locked = false } = {}) {
  if (locked || idleMs >= AWAY_IDLE_MS) return { left: true, back: false };
  return { left: false, back: !!left };
}

function keptText(at, read) { return `Kept warm ${hhmm(at)} · read ${tokensText(read)} from cache`; }
function stoppedText(reason) { return `Stopped keeping warm: ${reason}`; }

/** The button's tooltip line for one tab: p from plan(), k its kept entry. */
function tabLine(p, k) {
  if (k?.state === 'dropped') return `stopped: ${k.reason}`;
  if (p.action === 'skip' || p.action === 'drop') return p.reason;
  if (p.reason === 'working') return 'working';
  const next = `next ping ${hhmm(p.dueAt)}`;
  return k?.lastPing ? `kept warm ${hhmm(k.lastPing.at)} · ${next}` : next;
}

module.exports = { LEAD_MS, MAX_MS, TICK_MS, AWAY_IDLE_MS, COLD_SHARE, COLD_MIN_WRITE, PING_TEXT, hhmm, tokensText, plan, receipt, watchBack, keptText, stoppedText, tabLine };
```

```js
// Keep warm (docs/plans/keep-warm.md): while it's on, every conversation with a
// warm one-hour cache gets one tiny message shortly before that cache would
// expire, so the first message after lunch reads the conversation from the
// cache instead of writing it all again. keepwarm.js has the rules; this runs
// them against the open tabs, keeps the PC awake and tells the panel.
const kw = require('./keepwarm');

/**
 * d: what this needs from main, read when it's used.
 *   manager, panel: getters
 *   log, send, powerSaveBlocker (Electron's), CAPTURE
 *   leadMs: dev and e2e only, how long before expiry a ping goes (SHELLBY_KEEPWARM_LEAD_MS)
 *   now, setInterval, clearInterval: tests bring their own clock
 */
function createKeepWarm(d) {
  const now = d.now || Date.now;
  const every = d.setInterval || setInterval;
  const stopEvery = d.clearInterval || clearInterval;
  const lead = d.leadMs || kw.LEAD_MS;
  let on = null;           // { endsAt, left } while it's on
  let timer = null;
  let blocker = null;      // the powerSaveBlocker's id while it's on
  let lastPlan = [];
  const kept = new Map();  // tabId -> { state: 'kept' | 'dropped', reason, lastPing: { at, read } | null }
  const inFlight = new Set();
  const isWarm = p => p.action === 'ping' || p.action === 'wait';

  function tabsNow() {
    return [...d.manager.tabs.values()].map(t => ({
      id: t.id, title: t.title, saved: !!t.saved, inTerminal: !!t.inTerminal,
      hasProc: !!t.session.proc, busy: !!t.session.busy, pending: t.session.pending.size,
      crew: t.session.runningCrew().length, cache: t.session.cache || null,
    }));
  }

  function view() {
    return {
      on: !!on, endsAt: on ? on.endsAt : null,
      tabs: on ? lastPlan.map(p => ({ id: p.id, title: p.title, line: kw.tabLine(p, kept.get(p.id)) })) : [],
    };
  }
  function push() { d.send(d.panel, 'keepwarm', view()); }

  function arm() {
    if (on) return { ok: true, ...view() };
    const t = now();
    kept.clear();
    lastPlan = kw.plan(tabsNow(), kept, t, lead);
    const warm = lastPlan.filter(isWarm);
    if (!warm.length) return { ok: false, error: 'Nothing to keep warm: no conversation has a warm one-hour cache.', ...view() };
    for (const p of warm) kept.set(p.id, { state: 'kept', reason: null, lastPing: null });
    on = { endsAt: t + kw.MAX_MS, left: false };
    timer = every(tick, kw.TICK_MS);
    timer?.unref?.();
    // A laptop asleep at lunch pings nothing (held-service.js does the same for the reset queue).
    if (!d.CAPTURE) blocker = d.powerSaveBlocker.start('prevent-app-suspension');
    d.log.info('Keep warm on', `${warm.length} conversation${warm.length === 1 ? '' : 's'}`);
    tick();
    return { ok: true, ...view() };
  }

  function stop(why) {
    if (!on) return { ok: true, ...view() };
    on = null;
    stopEvery(timer);
    timer = null;
    if (blocker !== null) { d.powerSaveBlocker.stop(blocker); blocker = null; }
    kept.clear();
    d.log.info('Keep warm off', why);
    push();
    return { ok: true, ...view() };
  }

  // endsTurn: the line ends a ping's turn in the panel (boot.js). A tick's own
  // drop doesn't: that tab may be in the middle of a turn of yours.
  function drop(id, reason, endsTurn = false) {
    if (on) kept.set(id, { state: 'dropped', reason, lastPing: null });
    d.manager.note(id, { kind: 'keepwarm', warm: false, endsTurn, at: now(), text: kw.stoppedText(reason) });
  }

  async function ping(id) {
    inFlight.add(id);
    let r = null;
    try { r = await d.manager.ping(id, kw.PING_TEXT); } catch { /* it took up work of its own meanwhile: the next tick looks again */ }
    inFlight.delete(id);
    if (!r) return;
    const v = kw.receipt(r);
    if (!v.warm) drop(id, v.reason, true);
    else {
      const at = now();
      const k = kept.get(id);
      if (on && k) kept.set(id, { ...k, lastPing: { at, read: v.read } });
      d.manager.note(id, { kind: 'keepwarm', warm: true, endsTurn: true, at, read: v.read, text: kw.keptText(at, v.read) });
    }
    tick(); // the next due tab, if any: one ping at a time
  }

  function tick() {
    if (!on) return;
    const t = now();
    if (t >= on.endsAt) { stop('3 hours are up'); return; }
    for (const id of [...kept.keys()]) if (!d.manager.tabs.has(id)) kept.delete(id); // closed: just gone
    lastPlan = kw.plan(tabsNow(), kept, t, lead);
    for (const p of lastPlan) {
      if (p.action === 'drop') drop(p.id, p.reason);
      else if (isWarm(p) && !kept.has(p.id)) kept.set(p.id, { state: 'kept', reason: null, lastPing: null }); // warmed up since
      // One at a time (ping() ticks again when it's done), and never the same tab twice
      // in a row: its cache was just read, whatever the stamp says.
      const k = kept.get(p.id);
      const recent = k?.lastPing && t - k.lastPing.at < kw.LEAD_MS;
      if (p.action === 'ping' && !inFlight.size && !recent) ping(p.id);
    }
    push();
  }

  return {
    set: want => (want ? arm() : stop('turned off')),
    view,
    isKept: id => !!on && kept.get(id)?.state === 'kept',
    userSent: () => { if (on) stop('you sent a message'); },
    // Each idle reading away-service.js takes: the first short one after a long one means you're back.
    reading: r => {
      if (!on) return;
      const w = kw.watchBack(on.left, r);
      on.left = w.left;
      if (w.back) stop("you're back");
    },
    tick,
  };
}

module.exports = { createKeepWarm };
```

- [ ] **Step 1: Write the e2e script**

Create `scripts/e2e-keepwarm.js`:

```js
// ci: keep warm: a ping just before the cache expires, its dim line, the countdown, and coming back turns it off
// Keep warm (docs/plans/keep-warm.md) end to end against the fake CLI: with
// nothing cached it won't turn on; a reply cached for an hour, the mug pressed,
// a ping that reads the cache and leaves one dim line (no message of yours in
// the feed, the tab not left working); then a pretend absence and return turns
// it off, and so does a message you send. SHELLBY_KEEPWARM_LEAD_MS makes the
// ping due a second after the last reply.
//   node scripts/e2e-keepwarm.js
const { spawn } = require('child_process');
const fs = require('fs');
const os = require('os');
const path = require('path');

const ROOT = path.join(__dirname, '..');
const ELECTRON = path.join(ROOT, 'node_modules', 'electron', 'dist', 'electron.exe');
const PORT = 9441;
const HOUR = 60 * 60 * 1000;
const wait = ms => new Promise(r => setTimeout(r, ms));

async function cdp(wsUrl) {
  const ws = new WebSocket(wsUrl);
  let id = 0;
  const pending = new Map();
  ws.onmessage = e => { const m = JSON.parse(e.data); pending.get(m.id)?.(m); pending.delete(m.id); };
  await new Promise(r => { ws.onopen = r; });
  const send = (method, params = {}) => new Promise(r => { const i = ++id; pending.set(i, r); ws.send(JSON.stringify({ id: i, method, params })); });
  const ev = async expr => {
    const r = await send('Runtime.evaluate', { expression: expr, awaitPromise: true, returnByValue: true });
    if (r.result?.exceptionDetails) throw new Error(r.result.exceptionDetails.exception?.description || 'eval failed');
    return r.result?.result?.value;
  };
  return { ev, close: () => ws.close() };
}

(async () => {
  let fails = 0;
  const check = (ok, label) => { console.log(`${ok ? 'PASS' : 'FAIL'}  ${label}`); if (!ok) fails++; };
  const profile = fs.mkdtempSync(path.join(os.tmpdir(), 'shellby-test-'));
  fs.writeFileSync(path.join(profile, 'settings.json'), JSON.stringify({ onboarded: true, sounds: false, wander: false }));
  const app = spawn(ELECTRON, [ROOT, `--remote-debugging-port=${PORT}`], { stdio: 'ignore', env: {
    ...process.env, SHELLBY_USER_DATA: profile, SHELLBY_FAKE_CLAUDE: path.join(ROOT, 'test', 'fixtures', 'fake-claude.js'),
    SHELLBY_HOOK_PORT: '47957', SHELLBY_RECAP_TEST: '1', SHELLBY_KEEPWARM_LEAD_MS: String(HOUR - 1000),
  } });
  try {
    let target = null;
    for (let i = 0; i < 40 && !target; i++) {
      try { target = (await (await fetch(`http://127.0.0.1:${PORT}/json/list`)).json()).find(x => x.url.endsWith('panel.html')); } catch { /* starting */ }
      if (!target) await wait(500);
    }
    if (!target) throw new Error('panel.html never appeared');
    const panel = await cdp(target.webSocketDebuggerUrl);
    const poll = async (expr, ms = 10000) => { const end = Date.now() + ms; while (Date.now() < end) { if (await panel.ev(expr).catch(() => false)) return true; await wait(200); } return false; };
    const type = text => panel.ev(`(i => { i.value = ${JSON.stringify(text)}; i.dispatchEvent(new Event('input')); i.dispatchEvent(new KeyboardEvent('keydown', { key: 'Enter', bubbles: true })); })(SB.$('input'))`);
    const pressed = "SB.$('keepWarmBtn').getAttribute('aria-pressed') === 'true'";
    await wait(3000);
    await panel.ev("SB.setView('chat')");

    await panel.ev("SB.$('keepWarmBtn').click()");
    check(await poll("SB.$('toast').textContent.includes('Nothing to keep warm')"), 'with nothing cached it says so, and stays off');
    check(!(await panel.ev(pressed)), 'the mug is not pressed');

    await type('warm1h 40000');
    check(await poll('!SB.activeTab().busy && SB.activeTab().cache?.ttlMs === 3600000'), 'a reply cached for an hour');
    await wait(1500); // past the one-second lead: the ping is due as it turns on
    await panel.ev("SB.$('keepWarmBtn').click()");
    check(await poll(`${pressed} && /^Warm · \\d/.test(SB.$('keepWarmLeft').textContent)`), 'pressed, with the time left beside it');
    check(await poll("[...SB.activeTab().el.querySelectorAll('.keepwarm-mark')].some(m => /read 40k from cache/.test(m.textContent))", 15000), 'the ping leaves one dim line with what it read');
    check(!(await panel.ev("[...SB.activeTab().el.querySelectorAll('.msg')].some(m => m.textContent.includes('Keep-warm ping'))")), 'the ping itself is not in the feed');
    check(await poll('!SB.activeTab().busy'), 'the tab is not left working');
    check(await poll("SB.$('keepWarmBtn').title.includes('next ping')"), 'the tooltip says when the next ping goes');

    await panel.ev(`shellby.devAway({ idleMs: ${5 * 60e3} })`);
    check(await panel.ev(pressed), 'still on while you are away');
    await panel.ev('shellby.devAway({ idleMs: 0 })');
    check(await poll(`!(${pressed})`), 'coming back turns it off');

    await panel.ev("SB.$('keepWarmBtn').click()");
    check(await poll(pressed), 'on again');
    await wait(1000);
    await type('hello');
    check(await poll(`!(${pressed})`, 15000), 'a message you send turns it off');
    panel.close();
  } catch (e) {
    check(false, e.message);
  } finally {
    app.kill();
  }
  console.log(fails ? `\n${fails} failed` : '\nall passed');
  process.exit(fails ? 1 : 0);
})();
```

### Task 7: The live check on a real plan session (a person, or the agent with the user watching)

The fake CLI can't show that a real ping holds a real cache. This task needs the real Claude Code on the user's plan. It sends one real ping, about one cache read of the conversation's size. **Ask the user before running it.**

**Files:** none changed.

- [ ] **Step 1: Start a dev instance with a one-minute lead**

Run (PowerShell, in the worktree): `$env:SHELLBY_KEEPWARM_LEAD_MS = '3540000'; npm run dev:crab -- --real`
This makes a ping due 1 minute after the last reply, instead of 55 minutes. Plain `dev:crab` uses the fake CLI (`scripts/dev-crab.js` sets `SHELLBY_FAKE_CLAUDE` unless `--real` is passed).

- [ ] **Step 2: Warm a real conversation and arm it**

In the dev panel, open a conversation in a git project with a CLAUDE.md (Task 0's spike ran in a bare temp folder, so this is the only check against a real project's prompt). Send `Reply with one word: ready`, wait for the reply, then send `Reply with one word: again` and wait for that too. Two messages, because Task 0 found that a process's second turn always rewrites part of its first message (it read 21k and wrote 16k of a 35k prompt), which a first ping would report as cold. From the third turn on, a ping read 35,083 and wrote 2,624. Hover the context chip and confirm it says the cache is warm for about 60 minutes (one hour, not five). Press the mug.

- [ ] **Step 3: Read the receipt**

Within about 90 seconds, the conversation shows `Kept warm HH:MM · read Nk from cache`. N should be roughly the conversation's size: tens of thousands of tokens is normal for a fresh conversation, because of Claude Code's own setup. The context chip's warm countdown goes back to about 60 minutes.

- Press the mug again to turn it off.
