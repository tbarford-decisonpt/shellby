# The name and the crab

Shellby's code is [GPL-3.0](LICENSE), and that licence is about copyright. This
page covers the two things it deliberately doesn't hand over: the **name** and
the **crab as a mascot**.

Reserving them is allowed by the licence itself (GPL-3.0 §7(e)), and it isn't
there to make forking hard. It's there so that when someone downloads something
called Shellby, they know whose it is.

## What's reserved

- The name **Shellby**.
- The hermit crab used to identify this project, and the app and tray icons in
  [assets](assets) that depict him.

These are unregistered trademarks of x-salmon.

To be clear about where the line falls: the code that *draws* him, in
`src/renderer/critter/`, is GPL-3.0 like everything else, so a fork can keep the
drawing. What's reserved is using the name or the crab as the **identity of a
product**.

## Yes, go ahead

- Fork the code, change it, ship it. That's what the licence is for.
- Say your project is "based on Shellby" or "a fork of Shellby", and link back.
- Write about him, review him, screenshot him, put him in a talk or a tutorial.
- Make skins, packs and add-ons. Those are yours — see [docs/SKINS.md](docs/SKINS.md)
  and [docs/ADDONS.md](docs/ADDONS.md).

## Please don't

- Name your fork "Shellby", or anything a tired person would misread as Shellby,
  in its project name, app name, installer, domain or store listing.
- Use the crab or the icons as your own project's logo or app icon.
- Suggest your version is the official one, or that it's endorsed by this project.

If you publish a fork, **give it its own name and its own critter.** That's the
whole ask.

## Asking

Want to use the name or the crab for something that isn't listed here? Open an
issue. The answer is usually yes.
