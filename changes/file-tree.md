### New
- **All files, beside the chat.** The Trail's drawer is now the File manager, with two tabs: Trail, and All files (Ctrl+Shift+F). All files shows the whole project of the conversation you're in. Each file has its git mark and +/− since the last commit, and each folder sums up what's under it, so a closed folder still tells you where the work is. As Claude works, files light up purple when read, orange when written and green when a commit lands, and their folders open while they're lit. The branch row shows how far ahead or behind you are and opens the worktree and branch menu.

### Changed
- **Trail rows open in the file viewer.** A row's open button, a double-click or Shift+Enter shows the file in the viewer, as a file link in the chat does. Hold Ctrl to open your editor instead.
