- **Linear and Jira issues on Next up, if you want them.** Have a Linear or Jira MCP server in Claude Code? A quiet **Linear…** link turns up under a project's Next up list: pick the server, say which issues (*ENG*, or a JQL search), and they're ranked in with your tasks and GitHub issues. Claude reads them in the background through your own server, with only its reading tools, so there's nothing new to sign in to. **Do this** starts one in a copy on a branch named for it, and the draft pull request links back (*Fixes ENG-123*). No server, no link: nobody else sees a thing.
