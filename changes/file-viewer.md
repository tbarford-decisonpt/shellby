### New
- **See what a worktree changed, without leaving Shellby.** The Files button on each pane opens that conversation's folder. It lists what changed since its branch began, shows each file's diff with line numbers, and shows any file in colour. The list keeps up while Claude works. The branch chip and the Project page open it too, for your own checkouts and every worktree of a project.
- **File links open in Shellby.** Click a file Claude mentions and it opens in the viewer at that line. Ctrl+click opens your editor, as before.
