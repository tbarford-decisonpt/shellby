      Flaky tests

      Tests that failed and then passed with the code exactly the same, in Shellby's tabs. Fixing or quarantining one happens in a copy of the repository, on its own branch.

        Dependency watch

        Shellby asks each project's own package manager what's outdated and vulnerable (npm, pnpm and Yarn, pip-audit, cargo-audit, Go and govulncheck), which asks their registries about its packages. If something needs doing, he offers to bump it, run the tests and open a pull request.
