                          Sensors

                            Windows doesn't let normal apps read CPU temperature. LibreHardwareMonitor can (it's free and open source), and Shellby reads it from LHM's local web server. Nothing leaves your PC.

                            1. Install it: winget install LibreHardwareMonitor.LibreHardwareMonitor
                            2. Run it as administrator (it needs that to read the CPU's sensors).
                            3. In LHM, open Options → Remote Web Server → Run.
                            4. Optional: Options → Run On Windows Startup and Start Minimized, so it's always there.

                            LHM's web server is asking for a password. Turn off authentication in Options → Remote Web Server, then check again.

                            Alert settings

                            "Very hot" is 8°C past the line. Shellby waits about 20 seconds before reacting, so short spikes during a game load don't count. Small drives warn at 10% free instead. Clutter is what Docker and the package caches could give back.

                                                                          Time

                                                                          Shellby can keep track of how long you spend on each project, for timesheets and invoices. He works it out from what he already sees:

                                                                          • The window in front. An editor or terminal showing a project's folder, or the project's page on GitHub.
                                                                          • Claude at work. While Claude works in a project, your terminal and docs count for it.
                                                                          • Git. A commit, checkout or pull says which project you're in.

                                                                          The clock stops when you're away from the keyboard. Window titles are read to find the project and then forgotten: only the project, the day and the minutes are kept, on this PC. Nothing is sent anywhere.

                                                                                      How much can Shellby do?

                                                                                      Autonomous mode skips every permission check. Shellby and its helper agents can edit, run or delete anything your Windows account can, without asking. That includes running scripts it writes for itself. Use it only for tasks you'd trust to an unsupervised script.
