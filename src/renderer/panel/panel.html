                Sensors

                  Windows doesn't let normal apps read CPU temperature. LibreHardwareMonitor can (it's free and open source), and Shellby reads it from LHM's local web server. Nothing leaves your PC.

                  1. Install it: winget install LibreHardwareMonitor.LibreHardwareMonitor
                  2. Run it as administrator (it needs that to read the CPU's sensors).
                  3. In LHM, open Options → Remote Web Server → Run.
                  4. Optional: Options → Run On Windows Startup and Start Minimized, so it's always there.

                  LHM's web server is asking for a password. Turn off authentication in Options → Remote Web Server, then check again.

                  Alerts

                  "Very hot" is 8°C past the line. Shellby waits about 20 seconds before reacting, so short spikes during a game load don't count. Small drives warn at 10% free instead.

                                                        Claude Code decides how it signs in.                                                         How much can Shellby do?

                                                        Autonomous mode skips every permission check. Shellby and its helper agents can edit, run or delete anything your Windows account can, without asking. That includes running scripts it writes for itself. Use it only for tasks you'd trust to an unsupervised script.

                                                        Tabs in the same repository stop stepping on each other. Questions stay in your checkout; the first time a conversation goes to change a file, it moves into a copy on a branch named for the work. Each copy is a git worktree on its own branch, starting from your last commit; your own checkout and anything uncommitted in it stay as they are. Bring it home merges the branch back and the conversation carries on; Bring it home and finish also tidies the copy away. Bring it home and push sends it to the remote as well, and the folder menu can Push your branch or Bring all home at once. Ignored folders like node_modules aren't copied, so a copy may need its own install.
